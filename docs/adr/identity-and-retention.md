# Identity and minimum-retention boundaries

Status: foundation boundaries implemented; production identities deferred to the approved identity milestone.

Keep collector, attribution, content and API identities separate. Bicep declares these four potential managed identities without any role or Graph grant. No sender, agent runtime or approval identity is declared. The retired feasibility reader stays retired. Local processes have synthetic database credentials only. The database adapter refuses remote hosts and sanitizes driver errors so credential-bearing frames cannot reach routine traces.

The accepted baseline is seven days for raw evidence and thirty days for decisions. Foundation queues carry allowlisted fixture references rather than message bodies. Decisions have a thirty-day expiry checked by queries. SQL expiry is not a physical deletion service: timed deletion, backups and evidence lifecycle enforcement must be implemented in the retention milestone. Content text has no storage field or logging route; current model-absent processing stays unknown. Do not load production data into this local stack.
